# Design Guidelines: All'Ombra degli Ulivi - Villa Vacation Rental Website

## Design Approach
**Reference-Based Approach** - Drawing inspiration from premium vacation rental platforms like Airbnb and Booking.com, emphasizing visual storytelling and emotional connection to create desire for the vacation experience.

## Core Design Principles
- **Mediterranean Elegance**: Sophisticated yet warm aesthetic reflecting Puglia's charm
- **Visual-First Experience**: Hero imagery and photo galleries drive engagement
- **Effortless Navigation**: Intuitive structure for easy property exploration
- **Trust & Credibility**: Professional presentation building confidence

## Color Palette

### Primary Colors
- **Mediterranean Blue**: 210 65% 45% (primary brand color)
- **Warm Terracotta**: 15 55% 60% (accent for CTAs and highlights)
- **Olive Green**: 75 30% 40% (supporting natural tone)

### Neutral Foundation
- **Warm White**: 45 15% 97% (backgrounds)
- **Soft Cream**: 45 20% 94% (card backgrounds)
- **Charcoal**: 210 10% 25% (text)
- **Light Gray**: 210 8% 85% (borders, dividers)

### Gradients
- **Hero Overlay**: Subtle gradient from Mediterranean Blue to transparent over hero images
- **Section Transitions**: Warm cream to white gradients for visual flow
- **CTA Buttons**: Mediterranean Blue to deeper blue for depth

## Typography
- **Primary Font**: Playfair Display (elegant headers, villa name)
- **Secondary Font**: Inter (body text, navigation, forms)
- **Accent Font**: Dancing Script (decorative elements, quotes)

## Layout System
**Tailwind Spacing**: Consistent use of 4, 8, 12, and 16 units (p-4, m-8, gap-12, py-16) for harmonious spacing relationships.

## Component Library

### Navigation
- Clean horizontal menu with villa logo
- Sticky navigation with subtle shadow on scroll
- Mobile hamburger with elegant slide-out menu

### Hero Section
- Full-viewport image carousel of villa exteriors
- Overlay with villa name in Playfair Display
- Central booking CTA with blurred background
- Subtle scroll indicator

### Content Cards
- Photo-first cards with rounded corners
- Soft shadows for depth
- Hover effects with gentle scale transforms

### Gallery Components
- Masonry-style photo layouts
- Lightbox functionality for detailed viewing
- Room/area categorization tabs

### Forms & CTAs
- Rounded input fields with subtle borders
- Primary buttons in terracotta with Mediterranean blue hover
- WhatsApp integration button with brand green

## Page Structure

### Homepage Sections (5 total)
1. **Hero Carousel**: Villa exterior shots with booking prompt
2. **Welcome**: Brief introduction with villa highlights
3. **Rooms & Amenities**: Visual grid of key features
4. **Guest Reviews**: Testimonial cards with 5-star rating
5. **Location & Contact**: Map integration with contact CTAs

### Villa Details Page
- Room-by-room photo galleries
- Service icons with descriptions
- Interactive floor plan (if available)
- Booking availability calendar

## Images Strategy
- **Hero Images**: Stunning villa exterior, pool area, sunset views
- **Room Photography**: High-quality interiors showcasing each space
- **Lifestyle Shots**: Pool activities, outdoor dining, relaxation moments
- **Landscape Views**: Olive groves, Puglia countryside context

## Accessibility & Responsiveness
- High contrast ratios maintained across color palette
- Touch-friendly button sizes (minimum 44px)
- Progressive image loading for performance
- Screen reader optimized content structure

## Backend Admin Features
- Drag-and-drop photo management
- WYSIWYG content editing
- Service/amenity toggles
- Booking calendar integration
- WhatsApp contact management

This design creates an aspirational yet authentic representation of the villa experience, emphasizing the Mediterranean lifestyle and premium vacation rental positioning.
